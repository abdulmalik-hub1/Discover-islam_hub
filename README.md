# Discover Islam — GitHub Ready

A self-contained Islamic educational website designed in a premium green, cream, and gold editorial style.

## Included

- `index.html` — the complete website
- `islam-assets/` — all local visual assets used by the site
- Six Pillars of Faith section
- Five Pillars of Islam learning section
- Qur'an reader demo and Hadith library links
- Prophet Muhammad ﷺ learning section
- Beginner/New to Islam path
- Sources & references section
- Responsive mobile navigation
- No external image files are required for the visual design
- `.nojekyll` for straightforward GitHub Pages hosting

## Upload to GitHub

Keep `index.html` and the `islam-assets` folder together. Upload the contents of this extracted folder to the repository root.

For GitHub Pages: Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
